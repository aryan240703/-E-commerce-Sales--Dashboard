  📊 Aryan E-commerce Sales Dashboard (Power BI)

This project presents an interactive **E-commerce Sales Dashboard** built in **Microsoft Power BI** to analyze and visualize business performance across multiple dimensions. It highlights key metrics, customer insights, and category trends to support data-driven decision-making.

  🔑 Key Features
- **KPIs at a glance**  
  - Total Sales Amount: **170K**  
  - Total Profit: **18K**  
  - Total Quantity Sold: **1422**  
  - Average Order Value (AOV): **42.68K**

- **State-wise Sales Analysis**  
  Bar chart showing sales distribution across **Maharashtra, Madhya Pradesh, Uttar Pradesh, and Punjab**.

- **Category Performance**  
  Donut chart of quantities sold:  
  - Clothing: 19.48%  
  - Electronics: 28.49%  
  - Furniture: 52.04%

- **Monthly Profit Trends**  
  Bar chart tracking profit fluctuations, including months with **negative profit**.

- **Customer Contribution**  
  Sales breakdown by customers: **Hardeep, Gopal, Shubham, and Sandeep**.

- **Payment Mode Insights**  
  Donut chart showing payment mode distribution by category.

- **Sub-Category Profitability**  
  Profit analysis across **Bookcases, Tables, Chairs, Phones, and Printers**.
